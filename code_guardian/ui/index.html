Open the link printed in the terminal

This page only works from the link that code-guardian ui printed when it started. That link carries a one-time key, so no other website can use this page.

Look in the terminal window for the line that starts with code-guardian ui: open and open that link. If the terminal is closed, run code-guardian ui again.

Check a project folder

code-guardian reads the files in a folder and tells you what it saw. It never runs your code and nothing leaves this computer.

Paste the full path of the folder you want checked.
